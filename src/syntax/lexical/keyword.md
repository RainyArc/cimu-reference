# Keywords

## Keywords in use

Keywords below are used in specific context and may not be used as identifiers.

- struct
- enum
- interface
- union
- int
- float
- bool
- str
- void
- const
- var
- if
- else
- switch
- default
- for
- while
- break
- continue
- return
- goto
- scene
- fn
- await
- async
- import
- macro
- as
- nil

## Reserved keywords

Currently, keywords below have no special use. But in a future edition, these keywords may have special meaning.

- unsafe
- type
- mod
