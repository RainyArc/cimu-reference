# Identifiers

**IDENTIFIER** <i class="fa-solid fa-arrow-right"></i>
IDENTIFIER-HEAD IDENTIFIER-CHAR*

**IDENTIFIER-HEAD** <i class="fa-solid fa-arrow-right"></i>
UNICODE-LETTER | `_`

**IDENTIFIER-CHAR** <i class="fa-solid fa-arrow-right"></i>
UNICODE-LETTER | UNICODE-DIGIT | `_`

**UNICODE-LETTER**

All characters defined as `Letter(L)` in [Chapter 4.5, Unicode Specification 17.0](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-4/#G124142).

**UNICODE-DIGIT**

All characters defined as `Decimal_Number(Nd)` in [Chapter 4.5, Unicode Specification 17.0](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-4/#G124142).
