# Type System

The type system describes the kinds of values that Cimu programs may produce,
store, pass, and return.

Every expression has a type. Variables, constants, parameters, fields, function
results, and scene parameters also have types. A type may be written explicitly
in a type annotation, or it may be inferred from the surrounding program.

This chapter describes the meaning of types. The syntax used to write type
names is described in the syntax chapter.
